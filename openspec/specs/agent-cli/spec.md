# agent-cli Specification

## Purpose

AI Agent が Bash から Docraider の全機能を安全かつ一貫した機械可読契約で実行し、結果と失敗を自律的に判定できるようにする。

## Requirements

### Requirement: MCP機能のCLI網羅
システムは既存の全 MCP ツールに対応する CLI 操作を提供し、同じ入力に対して機能的に同等の処理結果を返さなければならない。(SHALL)

#### Scenario: 全操作の発見
- **WHEN** Agent が CLI のヘルプを取得する
- **THEN** ページ取得、サイトクロール、複数ページクロール、検索、文書取得・一覧、索引統計、サイト取得・一覧・削除、埋め込みバックフィル開始・状態取得の各操作が列挙される

#### Scenario: MCPとの処理整合
- **WHEN** 同じ有効な入力を対応する MCP ツールと CLI 操作へ与える
- **THEN** 表示形式を除く対象選択、永続化、副作用、および結果データが一致する

### Requirement: JSON優先の出力契約
CLI は既定で標準出力へ単一の妥当な JSON 結果を出力し、結果データ、警告、および操作識別子を機械的に判別可能にしなければならない。(SHALL)

#### Scenario: 操作成功
- **WHEN** CLI 操作が成功する
- **THEN** 標準出力は `ok`、操作識別子、結果データ、および警告配列を含む単一 JSON 文書となる

#### Scenario: ログ分離
- **WHEN** 操作中に診断ログまたは進捗メッセージが発生する
- **THEN** それらは標準エラーへ出力され、標準出力の JSON を破壊しない

### Requirement: 機械判定可能な失敗
CLI は入力不正、対象なし、設定不正、DB 接続失敗、外部サービス失敗、およびその他の失敗を、安定したエラーコードと非ゼロ終了コードで区別しなければならない。(SHALL)

#### Scenario: 入力不正
- **WHEN** Agent が必須引数の欠落または不正値を指定する
- **THEN** CLI は入力エラーを示す安定したコードと非ゼロ終了コードを返し、副作用を実行しない

#### Scenario: 外部サービス障害
- **WHEN** 有効な操作が埋め込み API または取得先の障害で完了できない
- **THEN** CLI は外部サービス失敗として識別可能な結果と非ゼロ終了コードを返す

### Requirement: 長大出力の制御
CLI は本文を返す操作で出力先ファイルと本文上限を指定可能にし、クロールのような長時間操作では逐次的に解釈可能な出力形式を選択可能にしなければならない。(SHALL)

#### Scenario: 本文のファイル保存
- **WHEN** Agent が文書取得で出力先ファイルを指定する
- **THEN** 本文は指定先へ保存され、標準出力の JSON には保存先と要約メタデータが返る

#### Scenario: クロール進捗
- **WHEN** Agent がクロール操作で逐次出力を指定する
- **THEN** CLI は各行が独立して解釈可能な JSON イベントとして進捗と最終結果を出力する

### Requirement: 安全なサイト削除
CLI はサイト削除時に対象サイト ID と一致する確認値を必須とし、不一致または未指定の場合は削除してはならない。(SHALL)

#### Scenario: 確認値の不一致
- **WHEN** Agent が対象 ID と異なる確認値でサイト削除を要求する
- **THEN** CLI は入力エラーを返し、サイトと関連データを削除しない

#### Scenario: 確認済み削除
- **WHEN** Agent が対象サイトを確認後、対象 ID と同一の確認値を指定する
- **THEN** CLI は削除を実行し、削除した文書数とチャンク数を JSON で返す

### Requirement: 設定解決とプロセス終了
CLI は明示的な設定パス、環境変数、および既定設定を決定的な優先順位で解決し、各操作後に自身が所有するリソースを解放して終了しなければならない。(SHALL)

#### Scenario: 明示設定の優先
- **WHEN** Agent が設定ファイルパスを明示する
- **THEN** CLI はその設定を他の自動検出候補より優先して使用する

#### Scenario: 短命操作の終了
- **WHEN** バックグラウンド worker を除く CLI 操作が完了する
- **THEN** CLI は DB 接続やブラウザを解放し、追加操作を待たず終了する

### Requirement: MCP後方互換性
CLI の追加後もシステムは既存の MCP stdio transport、ツール名、入力 schema、および応答形式を維持しなければならない。(SHALL)

#### Scenario: 既存MCPクライアント
- **WHEN** 変更前の契約を使用する MCP クライアントが各既存ツールを呼び出す
- **THEN** クライアント変更なしで従来どおり応答を受け取る
